## 📥 How to download the launcher

To get started, navigate to the release page.

## ⚙️ Setting up the application

Once the download finishes, follow these steps to run the software.

1. Locate the file you just saved.
2. Double-click the file to open the launcher.
3. Windows might show a security window. Click "More info" and then "Run anyway" if prompted.
4. The launcher window will appear on your screen.

## 🛠️ Configuring your profile

The launcher creates a default profile for you. You can change these settings to suit your needs.

1. Open the Profiles tab in the application.
2. Click the plus icon to add a new profile.
3. Give your profile a name.
4. Select the version of Minecraft you want to play.
5. Choose your Java version. The launcher requires Java 21 to run modern versions of the game.
6. Set the memory allocation. Allocate at least 4 gigabytes of memory for a smooth experience if your computer has enough capacity.
7. Save the profile changes.

## 🎨 Using skins and capes

You have tools to change how your character looks in the game.

1. Navigate to the Skin Manager tab.
2. Upload an image file of your choice for your character skin.
3. You can also attach a cape file to your account through the Cape Manager.
4. Click Apply to save these changes to your profile.

## 📦 Installing mods and add-ons

The software allows you to install many types of Minecraft mods.

1. Navigate to the Modpack Manager.
2. Select your desired environment, such as Fabric, Forge, Quilt, or NeoForge.
3. You can import modpacks directly from files on your computer.
4. The launcher will detect your game directory automatically.
5. Save your settings and launch the game to apply the mods.

## 🖥️ System requirements

Ensure your computer meets these requirements to run the launcher and the game smoothly.

- Operating System: Windows 10 or 11.
- Processor: Intel Core i5 or AMD equivalent.
- Memory: 8 gigabytes of RAM or more.
- Storage: 2 gigabytes of space for the launcher and game files.
- Graphics: Dedicated graphics card with support for OpenGL 4.5.
- Java: Java 21 installed on your system.

## ❓ Frequently asked questions

**Does this launcher work without a premium account?**
Yes, the launcher supports offline mode. You can play without a premium Minecraft account by selecting the offline login option.

**How do I update the launcher?**
The software includes an auto-update feature. It checks for new versions every time you start the program. It will prompt you to update if a newer version exists.

**Where does the launcher store game files?**
By default, the application uses the standard Minecraft folder in your user data directory. You can change this path in the settings tab if you prefer to keep your files in a different location.

**Can I run shaders?**
Yes, the launcher supports Iris shaders and OptiFine. You can install these as mods or as specialized versions via the profile creator.

**Is it safe to use?**
The launcher follows standard protocols for handling game files and account authentication. It does not store your account passwords in plain text.

**How do I change the look of the app?**
The launcher has a fluent user interface. You can switch between light and dark themes in the interface settings menu.

**What is the portable mode?**
Portable mode keeps all your settings and game files inside the folder where the launcher resides. This is useful if you want to run the launcher from a USB drive or a specific folder on your PC.

**What if the game crashes?**
Check the logs tab in the launcher. The log shows exactly what happened during the game startup. If you see an error related to Java, make sure you have the correct version installed. If a mod causes a crash, the log usually identifies the specific file that caused the issue.

**Can I manage multiple game directories?**
Yes, you can create separate directories for each profile. This keeps your modded game files separate from your vanilla game files.

**Where can I find more help?**
If you have questions that aren't covered here, check the issue tracker on the official repository. Always provide your log file when asking for support so others can help you identify the problem.
